# Scopo

Questa directory contiene le sessioni che implementano un plan in `.kilo/plans` compattate con `/compact` in modo da poter eventualmente fare domande in futuro su quanto è stato fatto e perché.

Possono anche contenere sessioni di Ask non correlate ad un plan.

Se si riferiscono ad un plan, il nome del file in `.kilo/sessions` è lo stesso del piano che implementano se implementano un piano, altrimenti è nella forma `YYYYMMDD-HHMMSS-titolo-sintetico`.
